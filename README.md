# AI Friend Bot

Телеграм-бот на aiogram, который ведёт себя как живой человек:
- отвечает на сообщения в чате/ЛС (с памятью контекста в SQLite),
- время от времени комментирует новые посты в твоём канале (вероятность зависит от "настроения"),
- генерация через Ollama Cloud,
- периодически бэкапит базу данных в приватный GitHub-репозиторий.

## 1. Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Убедись, что в системе установлен `git` (нужен для бэкапа):
```bash
git --version
```

## 2. Настройка

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

Обязательные поля:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `CHANNEL_ID` | ID канала (бот должен быть в нём админом) |
| `REACTION_CHAT_ID` | Куда бот будет писать реакции на посты (обсуждение канала или отдельный чат) |
| `OLLAMA_API_KEY` | Ключ Ollama Cloud |
| `GITHUB_TOKEN` | Personal Access Token с правом `repo` на нужный репозиторий |
| `GITHUB_REPO` | `username/repo` |

Как узнать ID канала/чата: перешли любое сообщение из него боту [@userinfobot](https://t.me/userinfobot) или добавь бота [@RawDataBot](https://t.me/RawDataBot) временно в чат.

**Важно про GitHub-токен:** используй *classic* token с правом `repo`, либо fine-grained token с доступом Read/Write к содержимому конкретного репозитория. Храни `.env` вне git (он уже не должен коммититься).

## 3. Запуск

```bash
python main.py
```

Бот сразу начнёт отвечать в чатах. Первый автоматический бэкап произойдёт через `BACKUP_INTERVAL_HOURS` часов после старта — если хочешь бэкап сразу при запуске, можно временно вызвать `python -c "import github_backup; github_backup.backup_database_sync()"`.

## 4. Как это работает

### Настроение (mood.py)
Каждые `MOOD_UPDATE_INTERVAL_HOURS` часов настроение бота (0–100) случайно смещается. От него зависит:
- вероятность реакции на пост в канале (между `REACTION_PROB_MIN` и `REACTION_PROB_MAX`),
- тон ответов (описывается в системном промпте).

### Реакция на посты (handlers/channel.py)
На каждый новый пост в канале бот бросает "монетку" с вероятностью, зависящей от настроения. Если решает отреагировать — просит модель написать короткий человеческий комментарий и постит его в `REACTION_CHAT_ID` с небольшой случайной задержкой (2–12 сек), чтобы не выглядеть мгновенным ботом.

### Чат (handlers/chat.py)
Отвечает на любое текстовое сообщение (кроме команд, начинающихся с `/`) в любом чате, где есть бот. История переписки по каждому `chat_id` хранится в SQLite и передаётся модели как контекст (последние `HISTORY_LIMIT` сообщений).

### Бэкап (github_backup.py)
По расписанию: клонирует/обновляет локальную копию репозитория → удаляет старый файл БД в репо → делает безопасный snapshot текущей `bot.db` (через SQLite backup API, не блокируя работающий бот) → коммитит и пушит.

## 5. Идеи для развития
- Хранить отдельную историю "мыслей" бота, чтобы он мог сам иногда писать в канал/чат первым (не только отвечать).
- Добавить лимит скорости ответов на пользователя, чтобы не тратить бюджет Ollama Cloud.
- Добавить команду `/mood` (только для себя) для отладки текущего настроения.
- Squash истории бэкап-репозитория (`git commit --amend` + `push --force`), если не нужна история версий БД — сейчас каждый бэкап создаёт новый коммит.

## 6. Ограничения и что учесть
- Бот отвечает **на любое сообщение от любого пользователя** в чатах, где он есть — если добавишь его в группу с другими людьми, он будет общаться со всеми. Если хочешь ограничить только собой, добавь проверку `message.from_user.id == YOUR_ID` в `handlers/chat.py`.
- Все сообщения (включая от посторонних) сохраняются в SQLite и позже уезжают в твой GitHub-репозиторий — держи его приватным.
- `channel_post` хендлеры видят посты только если бот добавлен в канал администратором.
